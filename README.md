🎵 Musify – Modern Web Music Player

Musify is a modern web-based music player designed with a clean glassmorphism interface and responsive layout. Users can upload, organize, search, favorite, and play local audio files directly within the browser.

Built using HTML, CSS, and JavaScript, Musify demonstrates modern front-end development concepts including responsive design, audio handling, local storage, and interactive UI components.

Whether you’re looking for a personal music player or a front-end portfolio project, Musify provides a solid foundation with an elegant user experience.

Features

🎵 Music Library

* Upload local audio files
* Dynamic music library management
* Song listing with metadata
* Delete tracks with automatic memory cleanup (revoking object URLs)

🔍 Search System

* Search songs instantly
* Filter music library (All vs. Favorites)
* Fast and responsive results with helpful empty-state feedback

❤️ Favorites

* Add songs to favorites
* Manage favorite tracks
* Quick access to saved music synchronized via LocalStorage

⏯️ Music Controls

* Play / Pause (toggle directly from player or list item)
* Previous Track & Next Track
* Seek Progress Bar with live time updates
* Volume Control with mute toggle
* Audio error handling for unplayable or corrupt audio

⌨️ Keyboard Shortcuts

* `Space`: Play / Pause toggle
* `ArrowLeft`: Seek backward 5 seconds
* `ArrowRight`: Seek forward 5 seconds
* `ArrowUp`: Increase volume (+5%)
* `ArrowDown`: Decrease volume (-5%)
* `M`: Toggle mute
* `N`: Next track
* `P`: Previous track

🎨 Modern UI

* Glassmorphism design
* Spinning vinyl disc and album art playback animation
* Blurred background effects
* Smooth animations and hover states
